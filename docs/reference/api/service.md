# Service API

Auto-generated reference for the [`Service`][unshackle.core.service.Service] base class that every
service plugin subclasses. `Service` is one of three title sources: the remote client and the import are
the other two. The licence callbacks, the sample decrypter and the event hooks come from the shared base,
`unshackle.core.title_source.TitleSource`, and this page shows them on `Service`. See
[Creating a Service](../../dev/creating-a-service.md) for a guided walkthrough and
[Service Architecture](../../dev/service-architecture.md) for the wider object model.
